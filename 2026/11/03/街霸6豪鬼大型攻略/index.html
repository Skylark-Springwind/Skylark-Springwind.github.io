一、角色定位：用 1000 血买来的工具箱

1.1 一句话结论

豪鬼是全游戏最全能的角色，代价是全游戏最低的血量（9000）。

他不是”难角色”，他是”贵角色“——每一次交互都在花钱，而钱包只有 9000。

1.2 强弱结构

维度 评级 说明
立回（中距离） ★★★★★ 2MK 可取消下段、6MK/6HP 长距离脱节、三速波

1.3 与深红毒蛇的结构对比（迁移用）

这两人都是”高波动角色”，但税付在不同地方：

深红毒蛇 豪鬼
税的形态 操作难度（HJC、取消链、低空火腿） 血量（9000）
抗压 差（无常规无敌 OD，只能 SA2/SA3 凹） 好（OD 升龙 1-8F 完全无敌）
火力来源 必杀接必杀的取消链 普通技 → 单发必杀 → 击倒
失败的样子 做不到（掉连、接不上） 做太多（凹、乱跳、硬抢）
上分瓶颈 执行稳定性 风险管理
练习重点 手法（肌肉） 克制（决策）

这张表是本攻略最重要的一页。

毒蛇的局，输在”手不行”；豪鬼的局，输在”手太快”。所以从毒蛇转豪鬼，旧的手法资产几乎全部作废，但”确认”和”距离”这两项资产全部保值——而这两项恰好是毒蛇笔记里反复强调的东西（生驹的”确认是闸门”、老桑局的”距离管理”）。

结论：豪鬼的入门课不是连段，是”少送”。

1.4 9000 血的真实含义（反直觉）

新手以为”血少 = 容易死”。真正的机制后果是：风险收益比被改写了。

同样一个 50/50 猜拳，双方期望值相同；但**豪鬼输掉这个猜拳的代价，比对手高 11%**（10000/9000）。这意味着：

常见误判 实际情况
“我要靠进攻压死他” 进攻是对的，但赌博式进攻是负期望
“豪鬼就是莽” 职业豪鬼打的是确定性，不是莽
“血少所以要多打” 血少所以每次交互的质量更重要

推论：豪鬼的正确打法是提高确定性、降低赌性。 这跟他”杀意之波”的角色气质完全相反——这也是为什么大量豪鬼玩家卡在钻石上不去。

2.3 输入层：5 帧缓冲、窜招，以及「刷键该不该用」

这一节回答一个具体问题：豪鬼大量 0 帧目押，习惯是刷两下键，要不要改成只按一下？
答案：要，但要先分清「目押」和「TC」是两种东西。

先把数字说准

场景 提前缓冲 实际窗口
普通招式（目押、连段衔接） 最多提前 4F 5F
冲刺 / 起身凹 提前 7F 8F
0 帧目押（优势 = 发生） 优势 1F + 缓冲 4F 5F

所以”0 帧目押在街霸 6 实际上是 4 帧”——准确说是 5 帧（4 帧提前 + 本帧）。60fps 下 1 帧约 16ms，不影响结论，但既然是算帧，就说准。

结论先行：目押单按，TC 连打

类型 例子 打法 原因
目押（link） 5HP, 5MK；5MP, 2HP 单按一次 需要读时机，连打会污染反馈
TC / 取消（cancel） 6MP > 5MP；5MP TC 连打、越连越好 取消窗口宽，只需”尽快按”
特殊技 / 指令 6HP、623、236 单按 + 方向干净 问题是方向残留，不是频率

混用这两种是掉招的主要来源：把”连打”的习惯带到目押上，掉连；把”单按”的习惯带到 TC 上，反而慢一拍。

为什么刷键在目押上没有好处（三条）

① 它不扩大窗口。 窗口是游戏给的 5 帧，恒定。你按两下只是产生两个候选时刻，而人手连按的间隔在 2~4 帧之间浮动——覆盖是随机的，不是叠加的。你并没有变稳，只是把一次判断换成了两次赌。

② 它抹掉反馈（最致命）。 按两下之后，你无法分辨”我这一下是按早了还是按晚了”。而没有反馈就没有学习——这和你之前那条”后摇里按了没效果”是同一类问题：不是技术问题，是数据被自己遮住了。

③ 连段里有实际代价。 第二下会在第一下之后出招：变成空振、掉连，或者在对手已经落地时挥空被确反。练得越多，这个习惯越贵。

但 6HP / 5HP 窜招是另一件事

这不是按键频率问题，是方向残留问题。原因有两个：

  1. 6 会残留。 你刚按过前进、6MK、或者摇过半圈，方向还没回中，这时按 HP 就出成 6HP。
  2. SF6 每帧读 3 次输入（社区测试，WydD）。同一帧里出现多个方向时，游戏最终取哪个看起来是随机的——所以”按得更快”不是解法，**”更干净”才是**。

三条修正：

问题 做法
想要 5HP 却出 6HP 按之前先把方向回中 1~2 帧，宁可慢一点
想要 6HP 却出 5HP 顺序是「前 → 停 1 帧 → 按」，不是”边推边按”
前走中直接按 HP 别这么干，先停住再按

怎么验证（别信我，信你自己的表）

先做 K0.5（各 10 次粗测，2 分钟）：DR 2HP, 2MP 单按 10 次 vs 刷两下 10 次。

  • 两个数差距明显（单按明显更低）→ 刷键确实在替你干活，按 §2.3b 的锚点法改
  • 两个数接近（大概率）→ 刷键只是安慰剂，改成单按，把省下的注意力放到读时机上

只有两者接近、但你想进一步确认时，才做正式对照：

打法 成功 /20
A 单按一次
B 刷两下

如果 B 显著高于 A，那就是我判断错了，以你的实测为准。

找时机的正确工具（比刷键有用一万倍）

  1. 打开 设置 → 界面显示 → 可取消时机显示（头顶会出现红/绿条）
  2. 训练场把速度调到 50%
  3. 出招，盯住头顶条从红变绿的瞬间——那就是窗口打开的那一帧
  4. 记住那个”收招动作长什么样”，恢复 100% 速度再练

目押之所以叫”目押”，就是用眼睛看收招动作，不是用手指碰运气。刷键的本质是”放弃看，改用碰”——它解决的从来不是时机问题，是”我不知道时机在哪”的问题。而后者有更快的解法。

2.3b 为什么这个习惯在毒蛇身上从没被惩罚

这一节回答一个更根本的问题：同样是刷键，为什么在毒蛇身上无害，到豪鬼身上就变成掉招？

不是”毒蛇不需要精度”，是”毒蛇的错误看得见”

毒蛇 豪鬼
连段的主导结构 HJC、低空火腿、假电取消 = 取消（cancel） 2HP, 2MP、5MP, 2HP = 目押（link）
窗口位置 动作本身持续期间（十几帧） 对手硬直最后几帧（0~1 帧余量）
按早了会怎样 取消不出来 → 连段当场断掉 指令被吞 → 但刷键的第二下会”碰巧”接上
按两下的代价 无（取消本来就鼓励连打） 掉连、出成别的招、被确反

关键差别是「错误的可见性」。

  • 毒蛇按错：连段断了，慢动作里一目了然 → 你能从失败里学到东西
  • 豪鬼刷键按错：第二下蒙对，连段成立 → 你以为你按对了

刷键把 0 帧目押从一个可学习任务，变成了一个不可学习任务。
而毒蛇根本不会制造这种错觉，因为它的连段里几乎没有 link——它不给你犯这个错的机会，也不给你发现这个错的机会。

这跟你前面那条”后摇里按了也没效果”是同一个结构：不是技术问题，是数据被自己遮住了。 三个问题（后摇按了没用 / 波被防几帧 / 0 帧要不要刷键）其实是同一件事——用手感代替读数。

你举的那条：DR 2HP, 2MP 确实是 0 帧

用官方帧数验一遍（DR 中命中优势 +4）：

完全成立，也完全不容错。 这就是为什么它在录像里看起来”很顺”，实战里却常常莫名其妙断——不是你没练，是这个连接本来就只有一条缝。

余量公式（自己算任何一条连段）

余量 = 命中优势 −（下一招发生 − 1）
绿冲中的招，命中优势 +4。

豪鬼常用 link 按余量分档（官方 Year 4 数据）：

余量 连段 算式
0 帧 DR 2HP, 2MP (1+4)=5 vs 6F
0 帧 DR 2HP, 5MP (1+4)=5 vs 6F
0 帧 DR 5HP, 2MK (3+4)=7 vs 8F
0 帧 5HP, 5LP / 5MK, 5LP 3 vs 4F
1 帧 DR 5MP, 2HP ← 7.2 主练这条 (4+4)=8 vs 8F
1 帧 DR 5HP, 5MK (3+4)=7 vs 7F
1 帧 2MP, 5MP / 2MP, 2MP 6 vs 6F
1 帧 5MP, 2LP 4 vs 4F
2 帧 2LP, 2LP / 2LP, 5LP 5 vs 4F

读法：0 帧档必须单按，且必须靠视觉锚点；1 帧档单按也能稳；2 帧档容错已经够宽，连打的收益刚好抵消掉风险。

但先问一句：这条 0 帧值不值得练

0 帧目押的注意力成本是固定的，收益却差别很大。

情况 建议
能多打 400+ 伤害，或唯一进斩杀线 值得练，用视觉锚点
只多 100 伤害，且有 1 帧替代路线 换路线，把注意力留给立回
只是为了”看起来很帅” 不练

豪鬼的连段表里，很多 0 帧 route 都有 1 帧替代品（比如 DR 2HP, 5MP 和 DR 2HP, 2MP 同为 0 帧，但后续收尾可能不同）。先找替代，再决定练不练——这跟 DRC 那条”一样的钱先买稳的”是同一个判断。

怎么把”碰”改成”看”（针对 0 帧）

0 帧目押只有 5 帧窗口（1 帧 + 4 帧缓冲），60fps 下 83ms，不可能靠手感稳定。必须找一个视觉锚点：

锚点 怎么用 适用
可取消时机显示（红/绿条） 只在取消时有效，目押看不到 练 TC / DRC 用
对手的受击姿势 硬直结束前会开始”往回站”，那一帧就是窗口 通用，最可靠
自己的收招动作 2HP 收拳到胸前的某一帧 最稳定，因为是你自己的动作

训练步骤（10 分钟）：

  1. 50% 速度，只打 DR 2HP, 2MP，20 次，找”看到什么就按”
  2. 口头描述那个画面（”他肩膀往下塌的那一下”），描述不出来说明你还在碰
  3. 100% 速度，20 次，记录成功数
  4. 开随机防御，被防时必须停（练确认，别练手速）
  5. 单按 vs 刷键各 20 次，填上面那张 A/B 表

验收标准不是”20 次全成”，是”说得出你在看什么”。 只要说得出，成功率会自己长上去；说不出，成功率就是运气。

四、立回：豪鬼的地面

4.1 核心模型：三段距离

豪鬼的立回不是”一套拳脚走天下”，而是按距离切换武器。这是他与隆肯最大的区别（隆肯是”同距离不同选项”，豪鬼是”不同距离不同角色”）。

切换的逻辑：把对手逼进你想打的那一层，而不是被他拖进他想要的层。豪鬼的中距离是全场最强之一，所以默认答案是”守住中距离”，不是”往前冲”。

为什么真正的中枢是 5HP，不是 2MK？

中距离的主力按钮，不是”最快”或”最长”的那一个，是”被防最便宜”的那一个。

5HP 是这一排里唯一”三项都便宜”的：9F 不算慢、被防 -3 罚不到、打空不吃额外惩罚、伤害 800。而 2MK 虽然快 1 帧，被防 -6 意味着你白送 3 帧。

完整论证（含与肯 5MK 的对照、以及为什么我上一轮推荐的 6MK 是次优解）见 §4.2c。

2MK 的位置是”唯一的下段”，不是”中枢”。

它满足三件事：下段（对手必须蹲防）、可取消（能转成连段）、能复合兜底。但它的死穴正是 -6：

2MK 必须复合，不能裸出。
2MK > 236LP 是标准复合（被防推开后实际无责；命中就是连段）。
备忘录写”中距离①：下中脚+轻波动【0~+4】—— 无脑复合，骚扰，怕迸”，说的就是这条。

分工一句话：2MK 负责让他蹲，5HP 负责在他站着的时候把钱收走。

4.2b 1.5 格「死区」：为什么这里不该有专属按钮

起因：实战出现一个暧昧距离（约 1.5 格）——2MK 打不到、波不安全、2MK 会被差合。对策是用 6MK（有下段回避性能）。

也就是说 6MK 是一把设计上”惩罚空振”的招。你在死区按它，赌的是”他正好走进来”；赌输了不是 -4，是 19F 的自由落体。

② 6MK 是上段——它躲下段的同时，也躲开了蹲着的人

你说它有”下段回避”，这个观察和”它是上段”其实是同一件事的两面：

一个把身体压低的招，打点必然偏高。 判定框压低让它躲过对手的下段，但也让它从蹲着的人头上扫过去。

这也是本系列的第四次同一个结构：用体感代替读数。只不过这次不是高估风险，是给风险起了个过重的名字，然后为了躲开它去找了一个更差的按钮。

起因：看梅原录像，发现他中距离按的是 5HP（站重拳）和 6HP（前重拳），很少用 2MK。
背景：只玩过肯，对”站重拳当立回按钮”这件事没有概念。

**豪鬼多出来的那一项是”可取消”**——5HP 能取消成必杀技，这是肯 5MK 没有的。这一项让它从”试探”升级成”兑现”（见下）。

二、为什么它该当主力：三项都便宜

① 税低一半：-6 → -3

先给一个能自己算的公式：

被防 -X，能被「X 帧及以内」的招打中。（最短的招是 4F，所以 -3 及更好 = 罚不到）

被防 谁能罚到你
-3（5HP） 没有任何招能罚——最短的 4F 招要 4 帧才到，那时你已经恢复了
-6（2MK） 6F 以内的招全能罚，几乎每个角色的 2LP / 5LP / 5LK 都在这个区间

2MK 被防是”送礼”，5HP 被防是”白拿”。 这两个按钮只差 1 帧发生，责任差了一整档。

② 命中能兑现，不用斗气

这是最关键的一条：

豪鬼的中距离按钮是唯一”命中即击倒”的免费路径。 2MK 起手给的是距离优势（+18），5HP 起手给的是一次压起身。

按前面算过的账：豪鬼的伤害 90% 来自压起身循环，不是来自单次伤害。所以 +47 击倒 的价值远大于 +18 距离。

③ 打空不吃额外惩罚

这一条直接推翻我上一轮的建议：

按钮 被防 打空
6MK -4 15F + 4F = 19F
5HP -3 18F，无额外惩罚

在”有可能打空”的距离上（也就是你说的 1.5 格死区），选打空不吃亏的那一个。 6MK 是设计上惩罚空振的招，5HP 不是。而且 5HP 比 6MK 还快 1 帧、伤害高 100、被防安全 1 帧。

§4.2b 里”站姿前走 → 6MK”这一行，应改为 5HP。 6MK 只在”确定他会走进来”时更优（射程略长、命中 +5）。

2MK 负责让对手不能一直站着；5HP 负责在你确认他站着的时候把钱收走。

下段的作用从来不是”打伤害”，是逼对手蹲；而蹲着的对手不会前走，站着的对手才是 5HP 的猎物。这是一个循环，不是两个选项。

修正一处旧结论：我此前写过”Lv3 和 OD 蓄力伤害都是 1350、被防都是 +1，但 OD 蓄力快 25 帧 → 普通 Lv3 只在斗气 0 格时用”。

这句话只在贴身距离成立，实际是错的。 实测显示 Lv3 的帧数收益远高于 OD（6 格 +42 vs +27），差距 15 帧。Lv3 的真正缺陷不是帧数，是 56F 发生——立回中出必被跳。

所以正确分工是：立回用轻/重波（0 成本），击倒后用 Lv3（对手躺着跳不了）。Lv3 不是”没钱时的替代品”，是”击倒后的专用工具”。

蓄力的真实成本（K1 + K2 数据合并）

档 发生 比 Lv1 慢 被防（4格） 命中 你买到的东西
Lv1 16F — +18 不击倒 免费接近
Lv2 31F +15F +18 击倒 只有击倒
Lv3 56F +40F +36 击倒 +18 帧 且 击倒

关键发现：Lv2 花了 15 帧，帧数收益是 0。

4 格距离下 Lv1 和 Lv2 都是 +18，一模一样；但 Lv2 慢 15 帧。所以 Lv2 多付的 15 帧，**买到的唯一东西是”命中即击倒”**。

Lv2 = 用 15 帧买一个击倒的波。 它的收益 100% 在命中后，0% 在被防后。

推论很直接：

Lv2 该对着”会动”的对手发，不是对着”会防”的对手发。 对手站着防，你白花 15 帧，还不如发轻波（同样 +18，快 15 帧，还不吃斗气）。

这也是为什么 K2 毫无难度：蓄力手法从来不是瓶颈，判断”该不该蓄”才是。 手法是 L1，判断是 L2——你现在刚跨过去。

中波是冗余档位：所有距离都不如轻波（2格差 1 帧、4格差 7 帧、6格一样废）。它的唯一理由是弹速快 2 帧，不是帧数。不要把它当”折中选择”。

「波动是拳脚的延伸」的机械含义：普通技射程固定、帧数固定；波射程可变、被防帧数随距离变、时机可延迟。普通技是常量，波是函数。Lv3 波就是「一个 +1 的 5MP，射程 100%」——你早就会用 +1 的 5MP 压制了，波只是把它装到了另一个射程。

5.3 压起身（Okizeme）：豪鬼真正的火力

先理解”偷帧”（Meaty）

这是豪鬼压起身体系的底层原理，理解了它，备忘录里所有的”卡帧”条目都不用死记。

原理：让招式的最后一帧有效判定落在对手起身的第 1 帧。因为攻击的判定持续多帧，越晚打中，对手的受击硬直结束得越晚，你剩下的优势就越多。

数学：一个 4 帧判定的招式，偷到最晚帧，等于白赚 3 帧。

5.5 瞬狱杀（CA）—— 本阶段封存

结论：从训练菜单里删掉。30 天计划不出现，实战不主动用，CA 状态下就打正常连段。

这条不是”这个招不强”，是”现在学它，性价比是负的“。

为什么封存（三条，按重要性排）

① 决策污染（最关键）

学会一个高回报选项之后，人会自动高估它的可用场景——心理学上叫可得性启发。落到实战里就是：

  • 你会开始”等”那个机会，而不是打正常连段
  • 击倒后本来该压起身，你在想”能不能接瞬”
  • CA 状态下血量低，你会觉得”必须靠这个翻盘”，于是放弃稳的打法

真正掉分的不是你按空了，是你为了它放弃了本来会赢的那条路。 这一条比按空严重得多，而且不会显示在战绩里。

② 失误代价不对称

结果 收益
按中 +4700 伤害
按空 -47 被确反 → 吃一套 3000+，而豪鬼只有 9000 血

按空一次等于三分之一条命。而且瞬狱杀只有 1F 无敌，所以按空的方式有很多种：对手跳了、对手后走了、对手出招比你快 1 帧——全都会变成送。

③ 它是”读”的技能，不是”执行”的技能

输入 LP·LP·6LK·HP 十分钟就能练熟。但什么时候按——那是要读懂对手习惯、读起身、读拆投时机——属于段位级判断，不是手法。

手法可以练，判断只能攒。在没有判断力的时候拥有这个招式，只会让你更早地做出错误决定。

本阶段 CA 状态怎么打

打正常连段，用 CA 版 SA3 收尾（伤害 +500）。 就这么简单。

不需要记任何额外东西。这就是”少一个选项，反而更强”。

解锁条件（三条全满足再学）

  • 30 天计划全部完成，结业标准达标
  • 能连打 10 局，CA 状态下一次都没尝试按瞬狱杀
  • 击倒后压起身执行率稳定 ≥90%（说明你已经没有”空窗期”去等花招）

8.2b 发波后的对空：为什么「按了没效果」是个误会

起因：习惯是发波时不摇升龙，理由是”都还在后摇里，按了也没效果”。
这个信念的问题不在于对错，而在于它永远不会被证伪——因为不试，就永远不知道。

✅ 2026-11-02 实测：摇得出来，升龙能出。信念已证伪。（波动实验室 D3b）

要拆开的两件事：

能不能早 结论
摇杆动作（623 的三个方向） 可以早，而且必须早 实测成立：动作在恢复里走完，出招正常
按键（P） 不能太早 落在”恢复结束的那一帧”附近才对

所以正确做法不是”等恢复完再摇”，是在恢复里把动作摇完，让按键卡在恢复结束。你觉得”按了没效果”，很可能是因为你连动作都等到恢复结束才开始——那时候已经晚了 3~5 帧。

代价有多大：过去每一局里”发波时被跳”的场面，你都是在主动放弃防守的状态下输掉的。你没输给对手的跳，输给了一句没验证过的话。而这句话之所以活了这么久，只因为它从不产生数据。

然后是最反直觉的一步：算一下反应跳到底来不来得及。

以 Lv1·L 为例：

56F > 46F。 也就是说，纯反应跳永远惩罚不了你的波——他跳到你头上的时候，你早就恢复完了。

这条推翻了「波怕跳」的通俗说法。真正的情况是：
能惩罚你的不是反应跳，是预判跳——他在你按下 236P 之前就已经起跳了。
换句话说，**”被跳波”不是距离问题，是节奏被读到了**。这也正好解释了为什么连发两波最危险：不是因为第二发更好反应，是第二发的时刻可预测。

唯一的真危险情形：他已经在你按下之前起跳，你放波时他正在空中 → 你的 30F 后摇刚好覆盖他落地的时间。这就是”安全波”要处理的事。

所以”安全波”有两个定义，别混

意义 定义 失效时的表现
立回安全 被防不亏，对手不能确反 被 2MK / 5MK 罚
对空安全 对手预判跳也赶不上你的恢复结束 被跳入打中

这两个是独立的。 一个波完全可以”被防 -4、完全安全”，同时”对空极不安全”——因为你在后摇里，什么都做不了。

所以真正该记的不是”这波几帧”，是：

安全波 = 站在”他预判跳过来也落不进我后摇”的距离之外发。

这条就是 波动实验室 D8 要测的东西。

行动项：发完波，眼睛立刻回到对手身上，手上开始摇 623。不是等看到跳再摇——那时候你已经慢在动作上了。

8.2c 「古烈点」：豪鬼有没有一个安全波距离

起因：安全波（safe fireball）这个概念确实出自古烈——特定距离的轻波，对手防住后跳入，古烈来得及脚刀。
这个判断是对的，但它的机制经常被说反。

古烈点真正成立的原因：不是他快，是波慢

常见说法是”古烈恢复快所以能对空”。不对。真正的因果是：

慢波强迫对手的起跳必须晚。

对手要跳过波，必须等到波快要打到他时才起跳——跳早了，落地时波还没到，反而被波打中。所以他被弹速卡在一个很晚的起跳时刻上；而古烈早在这个时刻之前就恢复完了，于是脚刀成立。

所以”古烈点” = 弹速把对手的起跳时刻推到你恢复之后的那个距离。 关键变量是弹速，不是恢复帧。

豪鬼的结构差异（这条很重要）

豪鬼 Lv1 的三只手全体都是 46F，蓄力到 Lv2/Lv3 才是 60F / 82F。也就是说：

古烈 豪鬼
恢复时间 长，且随版本变动 固定 46F（Lv1）
弹速 慢 未知
安全距离由什么决定 恢复长 + 弹速慢 几乎只由弹速决定

结论：豪鬼有没有古烈点，答案完全押在弹速上。而弹速恰好是官方帧数表唯一没给的那一项。

好消息：你不需要单独去测弹速。波动实验室 D1 那条曲线（被防帧数 vs 距离）的斜率就是弹速——距离每远一格，你多赚的帧数越多，赚得快就说明弹速慢。D1 做完，弹速自动就有了。

可操作的定义（不用公式）

安全波距离 = 在这个距离上，对手的一次起跳无法同时完成「躲过波」和「打到你」。

他只能二选一：要么跳早了被波打中，要么跳晚了被你升龙。只要这个”二选一”成立，这个距离就是你的古烈点。

反过来，如果你发波的距离上他能”一跳两得”，那这一发就是纯赌。

怎么找：10 分钟扫描

见 波动实验室 D3c。做法很朴素：dummy 设「防御后最速前跳」，然后从贴身到全屏逐格测。

实测结果（2026-11-02）：豪鬼有古烈点，就在 4 格

4 格发轻波 → 对手防住 → 起跳 → 623LP 能打中。 ✅

t 发生了什么
0 你恢复
0~18 对手还在硬直里，动不了（+18 就是这 18 帧）

你的升龙约 t=20 就能出（反应 12F + 摇 3F + 发生 5F）。余量 25 帧以上，不是勉强。

由此修正一个理解偏差：古烈点不是”帧数高”

很多人以为古烈点的关键是”被防帧数够大”。真正的条件是三条同时成立：

# 条件 谁提供
1 波能打到对手 D1 的有效射程
2 距离够远，他跳过来要够久 距离本身
3 他是防住/挨打之后才跳，不是预判跳 波是否命中或防住

条件 3 是核心。 只要波被防住，对手就进了硬直，起跳时刻必然晚于你恢复。而”预判跳”能打到你，是因为他起跳时你还在 46F 收招里——这才是”被跳波”的真正来源，不是距离，是时机暴露。

三档距离因此各有失败原因：

距离 判定
2 格 条件 1 ✓、3 ✓，但条件 2 ✗：太近，他跳过来只要十几帧，你反应不过来
4 格 三条全 ✓ → 古烈点
6 格 条件 1 ✓（重波）、2 ✓、3 ✓，但他跳不过来——落点根本够不到你

所以古烈点是”距离 × 波种”的乘积，不是某一个距离。

6 格实测：不是第二个古烈点，是免跳区

我原来预测”6 格重波是第二个古烈点”。实测推翻：对手从 6 格起跳，落点到不了你身上。

但这不是失败，而是第三类安全：

# 类型 机制 你要做什么 收益
1 立回安全 被防不亏、不被确反 无 不亏
2 古烈点（主动对空安全） 他跳得到，但我来得及升 摇 623 罚他一次
3 免跳区（被动对空安全） 他跳过来打不到我 什么都不用做 省反应，零收益

免跳区 ≠ 安全区。 他跳不过来，但绿冲过来只要十几帧。6 格发重波的风险不在跳，在绿冲和前走。

真正的结构：古烈点是一条被夹在两侧的窄带

约束 需要 失效表现
他跳得到你 要近 太远 → 免跳区
你来得及反应 要远 太近 → 他落地你还在收招

一个要近、一个要远，所以窗口必然很窄。 4 格能成立不是运气，是这两条线刚好在那里交叉。这也解释了为什么古烈点这么稀有——它是几何上必然窄，不是运气问题。找到一个就够用，不用指望第二个。

待测的一格是 5 格——它是免跳区的边界。知道边界在哪，你就知道”从哪一格开始可以完全不管他的跳”，这比找第二个古烈点有用得多。

8.2d 波的第三种失败：被「承受」

起因：对杰米实战发现，前走快的角色会选择「边前走边蹲防」，甘愿吃几发波掉血，也要把距离推回中距离。

波有三种失败方式，性质完全不同

# 失败方式 对手做了什么 性质

2 被穿 OD 波、无敌技、抗波技 他用资源换

前两种是”他做对了一件事”，你可以改。第三种是他在做交易——而且这笔交易他认为划算。这是最难受的一种，因为它不产生”错误”，只产生”账单”。

而对你：波收的是”时间税”，他选择付”伤害税”。 你要的是”他停下来”，他给你的是”他掉血”。这两件事不等价，而血量是可以换回来的（下一局），时间不能。

真正的错误：波在”他能走”的时刻发

他前走的时候，你的波没有剥夺任何东西——他本来就要往前，吃一发不掉节奏，反而更接近目的地。

波必须发在”他不能走”的时刻：

时机 为什么有效
击倒后（压起身） 他躺着，走不了
他收招后 他在 recovery，动不了
他落地时 落地硬直
他被防后 他在格挡硬直里，前走被锁

波的价值 = 剥夺他的行动时机，不是造成伤害。 他愿意吃，说明你没剥夺到任何东西。

对策：他蹲防，你就投；他吃，你就 Lv2

这是完整的一圈，四个按钮各打一种反应：

他的选择 你的答案 为什么
前走，不防 2MK（8F，下段） 打移动中的脚
蹲防前走 投（走过去投） 防御挡不住投
蹲防 + 拆投 6MP（20F，唯一常规中段） 打开蹲防
吃波推进 Lv2 波 命中即击倒
站着等 波 正常兑现

最关键的一条是投。 他为了吃波而选择蹲防，等于主动交出防御姿态——而防御姿态的唯一天敌是投。他选的这个策略，正好落在投能解决的那一格。

波在这里的正确用法变了：不是”打他”，是逼他进入防御。他一旦决定防，投就打开了。这就是”波动是拳脚的延伸”的另一层——波不是伤害手段，是让对手二选一的工具，而二选一里必有一边是投。

为什么不建议用 6MK / 5HK 打蹲防（容易误判的地方）：

按钮 段位 对蹲防
6MK 上段 蹲着能躲，直接 whiff
5HK 上段 同上；但被防 +3（不是 -13，旧稿错），蹲空了才亏
6MP 中段 ✓ 唯一能打开蹲防

6MK 看起来像中段（踢腿、10F、脱节好），但它标的是上段，蹲着打空。对着蹲防的人按 6MK，等于免费送一个 whiff。

为什么 Lv2 是这里的最优解

他不怕掉血，但他怕被击倒。

掉血 击倒
收益性质 线性（每次 700） 复利（多一轮压起身）
对豪鬼 磨到死 真正的伤害来源

豪鬼的伤害从来不是波打出来的，是压起身循环打出来的。所以对付”吃波推进”的人，正确的交换不是”我多打他 700”，是”我换一个击倒“。

Lv2 之前分析过：多花 15 帧，4 格帧数收益为 0，唯一买到的就是”命中即击倒”。这个”唯一”正好是这里最需要的东西。 他不愿停，那就让他躺下。

⚠️ 前提：Lv2 发生 31F，他前走时你发得出来吗？如果距离已经推到 2 格，31F 足够他走到你面前。所以 Lv2 要在 4 格以上用，配合 D1 的射程表。

一个反直觉的重读

你说”他们还是回到了中距离的立回”。但换个角度看：他不是抢回了立回，他是用血量买了一个防御姿态。

  • 他推进时是蹲防状态 → 不能进攻，只能防
  • 他到达中距离时你刚发完波 → 你也不是主动状态
  • 所以这个局面不是”他赢回了立回”，是”双方都回到了中性，但他付了血“

在这个中性局面里，先动的人吃亏（会被 whiff punish）。他连续前走已经暴露了意图，所以该动的是你——不是发波，是走过去投。

统计指标：判断这笔交易谁在赚

一局结束后看两个数：

数 怎么记
波造成的总伤害 命中次数 × 700
他因此推进的格数 目测，从发波位置到他贴身

如果伤害 < 1500 而他推到了贴身，说明波在亏——这一局应该停发波，改打 2MK 和投。

反过来，如果他用血量换了 3 次贴身、每次都被你投或 2MK 打回去，那这笔交易是你在赚，可以继续发。

一句话：不怕他吃波，怕的是他吃完之后你没有下一步。

10.1 先分清三层：什么现在学，什么以后学

这一节比后面 30 天的日程更重要。学错了顺序，练得越多越乱。

层 内容 作用 什么时候学

核心原则：L3 不是”更难”，是”更花”。

它不会提高你的基础胜率，只在特定情境里多给一个选择。而每一个新选择都会抢走一点注意力——注意力是有限的，在你还没把 L1 变成无意识动作之前，L3 只会让你的决策变慢、变差。

判断某个内容属于哪一层，只看一个问题：
“如果我这局完全不用它，会不会输？”
会 → L1/L2，现在学。
不会 → L3，先放着。

瞬狱杀就是标准的 L3：不用它，一局都不会因此输；但用了它，一局可能因此输。所以它被单独封存（见 5.5）。

  • 波的完整曲线 ✅（2026-11-02，D1）：轻/中/Lv2 到 4 格止，OD 到 6 格，**重波与 Lv3 到 8 格+**；
    并得到外推判据「被防帧数 ≥ 总硬直 = 必然过远」。
  • 6MK 的 low profile 是否真实（§4.2b）：官方表未标。dummy 出 2MK / 2HK，看能否躲过。
  • 6MK 对蹲姿的实际表现：确认它是「蹲着 whiff」还是「蹲防能防」。这条决定它在本 matchup 能不能用。

  • 5HP 蹲着会不会 whiff：官方标上段，但站立重拳的判定框可能仍能打到蹲防。这条决定它能不能当无条件主力。

11.3 与毒蛇笔记的迁移对照（学习路径）

毒蛇的能力 迁移到豪鬼 说明
轻攻击三点确认 直接迁移 完全一样的技能，甚至更简单（豪鬼不用确认站蹲）
距离管理 直接迁移 老桑局学到的”不让他进距离”完全适用
确认（打没打到） 直接迁移 豪鬼的确认窗口更宽（5HP 19F、6HP 20F）
HJC / 低空火腿 / 假电取消 作废 豪鬼没有这套机制
抗压心态 反向迁移 毒蛇是”没凹只能守”，豪鬼是”有凹但会被读”
立回节拍器（数脚步） 必须重建 无波角色用位移换接触，有波角色用波换接触 → 时间单位从”步伐”换成”弹道飞行”。见 波动实验室
输入纪律（cancel 惯性） 必须重建 毒蛇连段以 cancel 为主（窗口十几帧，连打天然正确）；豪鬼以 link 为主（0~1 帧余量，连打遮住反馈）。刷键不是坏习惯，是过期习惯，见 §2.3b

两处真空白区：节拍器、输入纪律。它们的共同点是——旧角色不会惩罚你，所以从来没被暴露过。

所以你的实际起点不是”从零学豪鬼”，而是”带着两项核心资产换角色“。这比从零快很多，但也容易高估自己——因为豪鬼的失败模式不同（不是掉连，是送），旧经验反而会误导。

  10. +47 → 百鬼袭落地 → +2。
  11. 偷帧 = 让最后一帧判定打中起身第一帧，白赚 3-4 帧。

  16. CA 状态下就打正常连段，收尾用 CA 版 SA3，够了。
  17. 斗气剩 2 格以下，只留给 OD 升龙。
  18. DRC 连段是奢侈品（3 格），不是基本功；要练绿冲就先练 1 格的 6MP > CDR。
  19. 连段里的 , 和 > 是两种东西，目押不能当取消打。
  20. Burnout = 没有凹，豪鬼最怕的状态。
  21. 中距离是你最强的一层，守住它，别往前冲。
  22. “少一个选项”经常比”多一个选项”更强——前提是你还分不清什么时候该用。
  23. 豪鬼输的局，多半不是”打不过”，是”按多了“。
  24. 波不是打人的，是给对手设一个行动截止时间；收益来自他超时，不来自命中。
  25. Lv1 命中不击倒——它的价值 100% 在”我不亏”，0% 在”我打中”。兑现要用 Lv2/Lv3。
  26. 波体系真正的武器是「波-波-停」中间那个停：连发时他在读你，停顿的时候你在读他。
  27. 反应跳惩罚不了波（56F > 46F）——被跳波不是距离问题，是节奏被读到了。
  28. 安全波有两个定义：立回安全（被防不亏）≠ 对空安全（预判跳也落不进后摇）。
  29. 发完波手就开始摇升龙：动作在恢复里走完，按键卡在恢复结束。别把”动作”也等到恢复完。
  30. 古烈点成立的原因不是古烈快，是波慢——慢波逼对手晚跳，晚跳到不了。所以关键是弹速，不是恢复帧。
  31. 豪鬼 Lv1 全体固定 46F，安全距离几乎只由弹速决定；而弹速就是 D1 曲线的斜率，不用另测。
  32. 目押单按，TC 连打——这两件事混用是掉招的主因。
  33. 0 帧目押在 SF6 是 5 帧窗口（4F 提前 + 本帧）。刷键不扩大窗口，只抹掉反馈；没有反馈就没有学习。
  34. 6HP / 5HP 窜招是方向残留，不是按得不够快；解法是回中 1~2 帧，不是加大力度。
  35. 余量 = 命中优势 −（发生 − 1），绿冲中的招 +4。自己算，别背表。
  36. DR 2HP, 2MP 是 0 帧：2HP(+1+4=5) vs 2MP(6F)，只有一条缝。
  37. 刷键不是坏习惯，是过期习惯——毒蛇的连段全是 cancel（窗口宽），豪鬼的是 link（0~1 帧）。毒蛇不惩罚它，所以它从没被暴露。
  38. 0 帧目押的验收标准不是”20 次全成”，是”说得出你在看什么“。
  39. Lv2 花 15 帧，4 格的帧数收益是 0（同为 +18）；它买到的只有”击倒”。对着”会防”的人发 Lv2 = 白花 15 帧。
  40. 古烈点不是”帧数高”，是三条同时成立：波能打到 + 距离够远 + 他是防住之后才跳。豪鬼的点在 4 格轻波（已验证）。
  41. 4 格重波只有 +5，在射程内 ≠ 安全——这两件事必须分开看。
  42. 发完波摇得出生龙（已实测）。过去每次”发波被跳”，都是主动放弃防守输掉的，不是打不过。
  43. 对空安全有两种：古烈点（他跳得到，我罚他）与免跳区（他跳过来打不到我）。后者不用反应，但收益为零。
  44. 古烈点被两侧夹住——太近反应不及、太远跳不过来。窗口必然很窄，所以找到一个就够，别指望第二个。
  45. 免跳区 ≠ 安全区：6 格他跳不过来，但绿冲过来只要十几帧。风险换了个形式，不是消失了。
  46. 波的第三种失败是「被承受」——他吃 700 继续前走。前两种是他做错，这一种是他算清楚了。
  47. 波收的是时间税，他付的是伤害税。这两者不等价，而血量下局能换回来，时间不能。
  48. 波只在「他不能走」时发：击倒后、收招后、落地、被防硬直中。他前走时发波，等于没剥夺任何东西。
  49. 他蹲防，你就投——防御挡不住投。波在这里的作用不是打他，是逼他进入防御。
  50. 对付吃波推进的人用 Lv2：他不怕掉血（线性），他怕被击倒（复利）。
  51. 6MK 是上段，蹲着能躲——别拿它打蹲防，那是免费 whiff。打开蹲防只有 6MP（20F 中段）和投。
  52. 6MK 打空惩罚 19F（15F + 4F），比被防 -4 更重。它是设计上「惩罚空振」的招。
  53. 1.5 格死区只有 0.3 格宽，他前走 4~6 帧就消失。解法是等 5 帧，不是找新按钮。
  54. 射程是动态的：2MK 打不到停住的人，但打得到前走的人。差合的原因不是距离，是你在他停住时按了键。
  55. 6MK 打站姿，6MP 打蹲姿——两者不可互换。蹲防的人不攻击，所以 20F 的 6MP 慢但不危险。
  56. 「不利」不等于「不安全」：1.5 格轻波被防约 -3~-4，不被确反，只是失去主动。
  57. 中距离的主力不是最快的招，是被防最便宜的招——5HP 被防 -3，2MK 被防 -6，只差 1 帧发生。
  58. 5HP 命中 +3 能零斗气换一次击倒（5HP > 214HP~6P，2180 / KD+47）；2MK 命中 0 只能取消波或烧 3 格绿冲。
  59. 在可能打空的距离上，选打空不吃罚的招：5HP（0）而不是 6MK（+4F）。这是 1.5 格真正的答案。
  60. 站重拳 ≈ 肯的 5MK（同为 +3/-3），只是慢 2 帧、多 100 伤害、多了「可取消」。
  61. 6HP 的价值在位移不在帧数——它打后退的人，不是站定的人；对站定的人用 13F 是送抢先。
  62. 5HK 被防 +3，不是 -13（官方数据修正）。它是全表最强的中距离回报，开关只有「他蹲不蹲」。
